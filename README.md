# 🍕 Pizza Sales Data Analysis Project
This repository contains the files and analysis for a data analytics project focused on gaining insights into pizza sales performance. The goal is to visualize key trends, understand customer behavior, and calculate essential business metrics (KPIs) to drive decision-making.
## 🌟 Project Goal
To analyze pizza sales data and create an interactive dashboard that visualizes daily and hourly order trends, sales distribution by pizza category and size, and identifies the best and worst-selling pizza items.
## 📊 Key Performance Indicators (KPIs)
The following metrics were calculated to assess overall business performance:
1. Total Revenue: The sum of the total price of all pizza orders.
2. Average Order Value: The average amount spent per order.
3. Total Pizzas Sold: The sum of the quantities of all pizzas sold.
4. Total Orders: The total number of orders placed.
5. Average Pizzas Per Order: The average number of pizzas sold per order.
## 📊 Charts and Visualizations
1. Daily Trend for Total Orders: Create a Bar Chart to show how total orders fluctuate each day over time.
2. Hourly Trend for Total Orders: Create a Line Chart to pinpoint the busiest ordering hours throughout the day.
3. Percentage of Sales by Pizza Category: Create a Pie Chart to see the sales distribution across different pizza categories.
4. Percentage of Sales by Pizza Size: Create a Pie Chart to show customer preference for different pizza sizes.
5. Total Pizzas Sold by Pizza Category: Create a Funnel Chart to compare the volume of pizzas sold for each category.
6. Top 5 Best Sellers by Total Pizzas Sold: Create a Bar Chart to highlight the 5 most popular pizzas.
7. Bottom 5 Worst Sellers by Total Pizzas Sold: Create a Bar Chart to show the 5 least popular or underperforming pizzas.
## 🛠️ Technology Stack
* **Data Source:** **CSV file**
* **Analysis/Manipulation:** **Excel**
* **Database:** **MS SQL (Microsoft SQL Server)**
* **Visualization/Dashboard:** **Excel**
